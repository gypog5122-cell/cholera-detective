# 콜레라 탐정 — 1854 소호 사건 파일

존 스노(John Snow)가 1854년 런던 소호에서 그린 콜레라 점 지도를
8단계 추리 게임으로 만든 웹페이지입니다.

**▶ 플레이: https://gypog5122-cell.github.io/cholera-detective/**

## 무엇을 하는 게임인가

지도 한 장으로 범인(오염된 급수 펌프)을 찾아가는 과정을 따라갑니다.

1. 브리핑 — 1854년 소호와 "독기설"
2. 범인 펌프 — 사망자가 몰린 한가운데의 펌프 지목
3. 빈칸 두 곳 — 구빈원과 양조장 찾기
4. 모순 — "펌프 코앞인데 왜 안 죽었지?"
5. 반례 파일 — 멀리 살았는데 죽은 사람들
6. 결론 잇기 — 거리설·물설·독기설 중 무엇이 전부를 설명하는가
7. 손잡이 — 펌프 손잡이 제거는 정말 결정타였나
8. 사건 그 후 — 1855년 기각부터 1884년 콜레라균 발견까지

위쪽 단계 막대를 눌러 언제든 되돌아갈 수 있습니다.
지도는 드래그로 이동, 휠이나 +/− 로 확대됩니다.

## 자료 출처

- 지도 원본 — John Snow, *On the Mode of Communication of Cholera*, 2판(1855)
- 사망자·펌프 좌표 — Dodson & Tobler(1992) 디지털화 자료 (R 패키지 `cholera`, Peter Li)
- 일별 사망자 — R 패키지 `HistData`의 `Snow.dates`
- 해설 — Edward Tufte, *Visual Explanations* (Graphics Press, 1997), 2장 27~35쪽

지도를 그린 사람은 **존 스노**입니다. 터프티는 이 지도를 자기 책 31쪽에 싣고
구빈원·양조장 두 곳에 노란색 강조를 더했습니다.

거리는 지도 좌표를 미터로 환산한 근사치입니다.
